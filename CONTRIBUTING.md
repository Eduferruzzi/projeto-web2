# Contribuindo

## Branches
Cada pessoa trabalha na sua branch individual e abre PR para `main` na semana.
- Nome das branches: `dev/[nome]` → ex: `dev/antonio`, `dev/douglas`

## Commits
Seguindo a ideia dos commits semânticos para padronizar e facilitar

Formato: `tipo: descrição curta`

Tipos: `feat`, `fix`, `docs`, `refactor`, `style`, `chore`

Exemplos:
- `feat: tela de login com validação de e-mail`
- `fix: corrige máscara de CEP no autocadastro`
- `docs: adiciona documento explicando a estrutura do repositório`

etc.

## PRs
- Pelo menos um PR por semana
- Pressutto vai ser o reviewer principal, mas cada um pode ajudar
- O nome do PR pode ser o commit principal


## Fluxo de trabalho

Só para para facilitar

- Cria a branch com: `git switch -c dev/[nome]`

- Adiciona e commita as alterações
- Da um push na sua branch
- Cria o PR no github
- Alguém aprova e mergeia na main
